# Gradle Wrapper Setup

The Gradle wrapper files have been partially created. To complete the setup, follow these steps:

## Option 1: Generate Wrapper with Gradle (Recommended)

If you have Gradle installed:

```bash
cd workflow-orchestrator
gradle wrapper --gradle-version 8.5
```

This will download the wrapper JAR and create the `gradlew` scripts.

## Option 2: Use Maven First, Then Add Gradle

If you have Maven but not Gradle:

```bash
# Use Maven to build the project
mvn clean compile

# Install Gradle via SDKMAN (Mac/Linux)
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install gradle 8.5

# Then generate wrapper
gradle wrapper --gradle-version 8.5
```

## Option 3: Manual Wrapper Download

If neither Maven nor Gradle is available, you can manually download and set up Gradle:

### Mac/Linux:
```bash
# Download Gradle
wget https://services.gradle.org/distributions/gradle-8.5-bin.zip

# Extract
unzip gradle-8.5-bin.zip
export PATH=$PATH:$PWD/gradle-8.5/bin

# Generate wrapper
cd workflow-orchestrator
gradle wrapper
```

### Windows:
1. Download Gradle from https://gradle.org/releases/
2. Extract to `C:\Gradle`
3. Add `C:\Gradle\gradle-8.5\bin` to PATH
4. Open terminal in project directory
5. Run: `gradle wrapper`

## After Setup

Once the wrapper is generated, you can use these commands:

```bash
# Build project
./gradlew build          # Mac/Linux
gradlew.bat build        # Windows

# Run example
./gradlew runExample     # Mac/Linux
gradlew.bat runExample   # Windows

# Run tests
./gradlew test          # Mac/Linux
gradlew.bat test        # Windows
```

## Using Maven Instead

If you prefer to stick with Maven, that's perfectly fine! Both build systems are supported:

```bash
# Maven commands work out of the box
mvn clean compile
mvn test
mvn exec:java -Dexec.mainClass="com.akilisha.oss.roya.workflow.examples.CustomerSupportWorkflow"
```

## Files Created

The following Gradle files have been created:
- ✅ `build.gradle` - Build configuration (Groovy DSL)
- ✅ `settings.gradle` - Project settings
- ✅ `gradle/wrapper/gradle-wrapper.properties` - Wrapper configuration
- ⏳ `gradle/wrapper/gradle-wrapper.jar` - Will be generated by `gradle wrapper`
- ⏳ `gradlew` - Unix wrapper script (will be generated)
- ⏳ `gradlew.bat` - Windows wrapper script (will be generated)

## Quick Start Without Gradle Wrapper

If you want to use Gradle immediately without the wrapper:

```bash
# Install Gradle first (if not installed)
# Mac: brew install gradle
# Ubuntu: sudo apt install gradle
# Or use SDKMAN: sdk install gradle

# Then use gradle directly (without wrapper)
gradle build
gradle runExample
gradle test
```

After setup, verify everything works:

```bash

./gradlew --version

# Build the project
./gradlew build

# Run the example
./gradlew runExample
```

You should see the CustomerSupportWorkflow example execute successfully!
