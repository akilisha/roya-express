Welcome to the Payment Backend!

This is a static HTML page served by the embedded Jetty server.

You can test the following endpoints:

  • /auth/oauth (POST to initiate OAuth, GET for callback simulation)
  • /device (POST/PUT/DELETE/GET for device management)
  • /command (POST for generic JSON commands)
  • /payment-methods (GET to retrieve available payment methods)
  • /qr-code?amount=X&description=Y&paymentOption=Z (GET to generate QR code data)
  • /process-payment (POST to simulate payment processing)
  • /sse (GET for Server-Sent Events subscription)

Check the server console for logs of interactions.

For SSE, open your browser's developer console and navigate to the Network tab, then filter by 'EventStream' or 'SSE' after visiting /sse.
