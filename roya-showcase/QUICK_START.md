# Roya Showcase - Quick Start Guide

## 🚀 Getting Started

```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Visit http://localhost:3000
```

## 📁 Project Structure

```
roya-showcase/
├── frontend/          # Preact web app
│   ├── src/
│   │   ├── components/  # UI components
│   │   ├── pages/      # Page components
│   │   ├── hooks/      # Preact hooks
│   │   └── signals/   # Preact Signals state
│   └── package.json
├── backend/           # Code execution service (coming soon)
└── docs/             # Documentation site (coming soon)
```
