# Roya Showcase

Interactive demos, tutorials, and documentation for Roya Framework.

## Getting Started

```bash
# Install dependencies
cd frontend
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `frontend/` - Preact web application
- `backend/` - Code execution service (coming soon)
- `docs/` - Documentation site (coming soon)

## Features

- 🎯 Interactive code playground
- 📚 12 LangChain4j tutorials
- 💡 Real-world examples
- 🚀 Performance benchmarks
- 📖 Comprehensive documentation
