# Roya Showcase - Getting Started

## 🚀 Quick Start

```bash
cd frontend
npm install  # Already done! ✅
npm run dev
```

Visit **http://localhost:3000**

## ✨ What's Built

### ✅ Core Pages
- **Home** - Hero section, features, examples gallery
- **Tutorials** - All 12 LangChain4j tutorials with code examples
- **Examples** - Real-world examples (Coffee Shop, Customer Support, etc.)
- **Playground** - Interactive code editor with Monaco
- **Docs** - Documentation structure

### ✅ Components
- **CodeEditor** - Monaco Editor integration
- **Header** - Navigation with active states
- **Footer** - Links and branding

### ✅ Tech Stack
- **Preact** - 3KB framework
- **Vite** - Lightning-fast builds
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Monaco Editor** - VS Code editor in browser
- **Wouter** - Lightweight router
- **Preact Signals** - Reactive state management

## 🎨 Features
