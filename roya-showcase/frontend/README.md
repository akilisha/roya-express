# Roya Showcase Frontend

Preact-based showcase website for Roya Framework.

## Tech Stack

- **Preact** - Lightweight React alternative (3KB)
- **Vite** - Lightning-fast build tool
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Wouter** - Lightweight router
- **Monaco Editor** - Code editor (coming soon)
- **Preact Signals** - Reactive state (coming soon)

## Development

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Build

```bash
npm run build
npm run preview
```
